Codex Meter 隐私政策

更新日期：2026 年 9 月 29 日

Codex Meter 是夏韬开发的独立第三方 macOS 工具，用于展示 Codex 账户的使用限额、剩余额度、套餐和重置时间，并非 OpenAI 官方应用。

账户连接

商店版通过随应用提供的 OpenAI 开源账户运行组件，使用 OpenAI 官方网页进行账户验证。密码在官方网页中输入，不由 Codex Meter 的界面接收。登录令牌由运行组件保存在本应用的 macOS 沙盒容器中，用于保持登录并查询额度；不会复制其他应用的登录文件，也不会把令牌放入桌面小组件共享数据中。

额度与本地数据

应用定期向 OpenAI 服务查询账户限额。套餐、用量百分比、余额、重置时间和更新时间等结果保存在本机应用共享容器中，供主应用和桌面小组件显示。主题、仪表样式等偏好也在本机保存。应用不提供对话或代码生成功能，不需要读取你的聊天内容、提示词或代码项目。

网络请求与第三方服务

登录和额度请求由你的设备直接连接 OpenAI 服务。OpenAI 会处理完成这些请求所需的账户信息、认证信息以及网络请求信息，其处理受 OpenAI 隐私政策约束。Codex Meter 没有开发者自建的账户数据服务器，也不设置广告或跨应用追踪；随包组件的 analytics 选项被设为关闭。

本支持网站托管于 GitHub Pages。访问网站时，托管方可能处理 IP 地址及访问日志，详情参见 GitHub 隐私声明。

断开连接与数据保留

在应用中点击“断开”会调用账户退出接口并清除应用当前共享的额度快照。你的 OpenAI 账户不会因此被注销。macOS 可能保留此前渲染的小组件画面，直到系统下次刷新。卸载应用不一定自动移除 macOS 保留的容器文件；如需清理剩余本地数据，可联系开发者获取指导。OpenAI 已处理的数据由其自己的政策管理。

联系支持

如果你主动发送支持邮件，开发者会收到你的邮箱和邮件内容，并仅用于处理反馈。请勿发送密码、登录令牌或完整账户文件。你可以通过同一邮箱请求删除所提供的支持信息；法律另有要求的除外。
