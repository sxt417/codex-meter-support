TokenMeter 隐私政策

更新日期：2026 年 11 月 3 日

本政策适用于本地统计版 1.0.1（110）及后续采用相同数据处理方式的版本。开发者：夏韬。

本地文件与统计

TokenMeter 是 macOS 本地 Token 日志统计工具。用户通过系统文件选择器主动选择日志文件夹后，应用在本机解析 JSONL 用量记录，汇总输入、缓存输入、输出和总 Token 数量。统计仅覆盖所选日志，不能代表账户剩余额度或账单。

读取 JSONL 文件时可能遇到其他日志字段，但应用仅保留统计所需的数值、记录标识和时间信息，不展示、持久保存或上传日志中的消息正文、提示词或代码内容。应用不会修改原日志，不会读取其他应用的账号凭证，也不会执行外部命令。

授权与本机保存

文件夹授权凭据保存在应用自己的沙盒偏好中，用于后续只读访问。主应用在运行时每分钟重新读取一次。每日数字汇总和更新时间会保存在本机 App Group 容器中，供桌面小组件使用；原始日志、文件路径和文件夹授权凭据不写入小组件共享缓存。

读取失败、未授权或汇总超过 15 分钟未更新时，不显示旧统计数字。macOS 可能保留先前渲染的小组件画面，直到系统再次刷新。此有效期不表示磁盘缓存会自动删除。

“查看示例”明确使用示例数据，不读取用户日志，也不将示例写入小组件缓存。导出 CSV 时，用户自行选择保存位置；导出文件包含每日数字汇总。

网络、账户与追踪

本地统计版没有账户登录、实时在线额度查询、在线生成、广告、分析 SDK 或跨应用追踪。App 不向开发者或第三方服务器发送日志或统计数据。点击支持和隐私链接会使用系统浏览器访问本网站；网站由 GitHub Pages 托管，托管方可能处理 IP 地址和网站访问日志，详见 GitHub 隐私声明。

移除授权与删除

在应用菜单中选择“移除授权并清空统计”，即可移除应用保存的文件夹授权与当前统计，并清空共享汇总。此操作不删除原始日志、用户另存的 CSV，也不注销任何其他服务的账户。macOS 可能保留应用容器或系统备份；如需进一步清理，请联系开发者。旧版遗留的本地额度文件不由本地统计版读取。

支持邮件

若你主动发送邮件，开发者会收到邮箱地址及邮件内容，仅用于处理反馈。请勿发送密码、令牌、完整日志或其他个人敏感信息。可通过同一邮箱请求删除支持信息；法律另有要求的除外。
